01

NỀN TẢNG MÁY TÍNH · IAS

Chapter 00–01 · PDF + BỔ TRỢ
  • Architecture vs Organization: Architecture = ISA, kiểu dữ liệu, độ rộng bit, addressing, I/O nhìn từ phần mềm; Organization = datapath, control, mạch và cách phần cứng hiện thực ISA.
  • Structure / Function: CPU + Main Memory + I/O + System Interconnection. 4 chức năng: Data Processing · Data Storage · Data Movement · Control.
  • Abstraction & evolution: Application → Compiler → Assembly → Assembler → ISA / OS → Microarchitecture → Digital circuits. Thế hệ: Vacuum tube → Transistor → IC → tích hợp mật độ cao; Moore’s Law dẫn sang Memory Wall.
  • IAS / Stored-program: Lệnh và dữ liệu cùng nằm trong memory; 1,000 words × 40 bit. Number = sign + 39-bit value. Instruction word = 2 × 20-bit; mỗi lệnh: 8-bit opcode + 12-bit address.
  • IAS CPU & registers: CPU = ALU + Program Control Unit. MAR: địa chỉ; MBR: word dữ liệu; IR: opcode; IBR: lệnh phải; PC: word lệnh kế; AC/MQ: toán hạng-kết quả. Ví dụ lệnh: LOAD, STOR, JUMP, JUMP+.
02

TIẾN HÓA CPU · PERFORMANCE

Chapter 01 · PDF + BỔ TRỢ
  • CPU evolution & design: 4004 → 8008 → 8080 → 8086/8088 → 80286/80386 → 80486/Pentium → Pentium Pro/Core/multicore. x86 thường thuộc CISC; ARM thuộc RISC; embedded, MIC và GPGPU phục vụ nhu cầu khác nhau.
  • Tăng tốc & cân bằng hệ thống: Pipelining · Branch prediction · Speculative execution · Data-flow analysis · Superscalar · Register renaming. Cân bằng CPU–Cache–DRAM–I/O; Memory Wall = CPU nhanh hơn khả năng cấp dữ liệu.
  • Đo hiệu năng / công suất: Benchmark (SPEC); xét Performance, Power, Cost, Size, Security, Reliability. Active power ≈ C × V² × f × α; phân biệt Active/Dynamic và Static power; tăng V/f có giới hạn nhiệt, RC delay và latency.
  • Iron Law & metrics: CPU Time = IC × CPI × Cycle Time = (IC × CPI)/Clock Rate. CPIavg = Σ(fractionᵢ × CPIᵢ). MIPS = IC/(Time × 10⁶); MFLOPS = triệu phép FP/giây. Không so CPU chỉ bằng GHz.
  • Amdahl & fabrication: Speedup = 1 / [(1−P) + P/S]; song song lý tưởng: thay S bằng N. Phần không cải thiện giới hạn speedup. Yield = chip tốt / tổng die; flow: wafer → pattern → test → package → test.
03

INSTRUCTION CYCLE · INTERRUPTS

Chapter 02 · PDF + BỔ TRỢ
  • Stored-program & computer function: Data + instruction cùng memory; thực thi tuần tự trừ khi đổi luồng. 4 chức năng: Processing, Storage, Movement, Control.
  • Instruction cycle: Fetch → Decode/Interpret → (Indirect nếu cần) → Execute → Store/Write-back; Interrupt cycle có thể xảy ra theo điều kiện. State diagram biểu diễn các trạng thái/nhánh.
  • Polling vs Interrupt: Polling: CPU chủ động hỏi trạng thái. Interrupt: thiết bị phát IRQ; CPU hoàn tất instruction hiện tại rồi chuyển ISR. Types: Program · Timer · I/O · Hardware failure.
  • Xử lý nhiều ngắt: Lưu context → ISR → khôi phục → tiếp tục. Sequential: xử lý lần lượt; Nested: ngắt ưu tiên cao chen vào. Xét priority, enable/disable và tính re-entrant.
  • IAS trace: Theo chuỗi PC → MAR → MBR → IR/IBR → AC/MQ; ghi mỗi bước: register lấy giá trị từ đâu, giữ gì và thay đổi khi nào.
04

BUS · INTERCONNECTION

Chapter 02 · PDF + BỔ TRỢ
  • Modules & transfers: Processor, Memory, I/O. Truyền: Memory↔CPU; I/O↔CPU; I/O↔Memory qua DMA (Direct Memory Access).
  • System bus: Data Bus mang dữ liệu; Address Bus chọn vị trí; Control Bus: Read/Write, request/grant, interrupt, clock, reset. Bus width ≠ clock ≠ bandwidth.
  • Hierarchy & arbitration: Shared bus có thể bottleneck; multiple-bus giảm tải. Arbitration: centralized hoặc distributed; Master khởi tạo, Slave đáp ứng. Timing: synchronous (clock) vs asynchronous (handshake).
  • Point-to-point & QPI: Liên kết trực tiếp, packetized, phân lớp. QPI 4 layer: Physical → Link → Routing → Protocol. Physical: Phit 20-bit, 20 lanes + clock mỗi hướng. Flit 80-bit = 64 data + 8 header + 8 error. Ví dụ slide: 3.2 GHz DDR × 16 bit = 6.4 GT/s, 12.8 GB/s/hướng (25.6 tổng).
  • PCI Express: Point-to-point lane: x1/x4/x8/x16; tổng thông lượng tăng theo số lane. Slide Gen1–Gen5: 2.5/5/8/16/32 GT/s; tính theo rate × encoding/overhead × lane.

05

MEMORY HIERARCHY · CACHE BASICS

Chapter 03 · PDF + BỔ TRỢ
  • Memory trade-offs: 3 thuộc tính: Capacity · Access Time · Cost/bit. Nhanh hơn → đắt/bit; lớn hơn → thường chậm hơn và rẻ/bit.
  • Hierarchy: Registers → Cache → Main Memory (DRAM) → Secondary storage. Xuống cấp: capacity tăng, cost/bit giảm, access time tăng, CPU access frequency giảm.
  • Locality: Temporal: dùng lại gần đây; Spatial: địa chỉ lân cận; Sequential: lệnh/địa chỉ theo chuỗi. Cache line/block gom dữ liệu; L1/L2/L3, I-Cache và D-Cache.
  • Cache operation: Read hit: lấy từ cache; read miss: nạp block. Write hit/miss phụ thuộc write policy; theo dõi valid/dirty đúng nghĩa. Hit Ratio = hits/requests; Miss Ratio = 1−Hit Ratio.
06

CACHE MAPPING · POLICIES

Chapter 03 · PDF + BỔ TRỢ
  • Địa chỉ cache: Tag nhận diện block; Index/Line/Set chọn vị trí; Block/Word Offset chọn byte/word trong block. Số bit offset theo block size; index theo số line/set; còn lại là tag.
  • 3 mapping schemes: Direct: 1 block → 1 line; line = block mod số line. Fully associative: block vào bất kỳ line. Set-associative: block vào đúng set, chọn một way (2-way/4-way…).
  • Conflict & replacement: Direct đơn giản nhưng dễ conflict/thrashing. Khi set đầy cần chọn victim; LRU/FIFO/Random là các policy khái niệm thường gặp.
  • Write policies: Write-through: ghi cache + memory ngay. Write-back: ghi memory khi evict; dirty bit đánh dấu line đã sửa. Tách biệt write-allocate/no-write-allocate khi đề yêu cầu.
07

INTERNAL · EXTERNAL MEMORY

Chapter 03 · PDF + BỔ TRỢ
  • Chip & semiconductor: Memory cell lưu 0/1; tổ chức W words × N bits → capacity = W×N bits; 2ᵏ words cần k address lines. SRAM: nhanh, flip-flop, cache; DRAM: tụ điện, cần refresh, main memory.
  • ROM family: ROM cố định; PROM ghi 1 lần; EPROM xóa UV; EEPROM xóa/ghi điện; Flash xóa theo block. SRAM/DRAM volatile; ROM/Flash non-volatile.
  • Magnetic disk: Platter, head, spindle, actuator; Track/Sector/Cylinder. Thời gian: Access ≈ Seek + Average rotational latency + Transfer. Average rotation (ms) = 30,000/RPM.
  • RAID & Flash/optical: RAID 0 striping/no redundancy; 1 mirror; 2 ECC; 3 byte+parity disk; 5 block+distributed parity; 6 dual parity. NOR: truy cập firmware; NAND: page/block, USB/SSD. SSD có latency thấp/IOPS cao nhưng có wear và erase-block. Optical: CD-ROM, CD-R, CD-RW; DVD 4.7 GB (dual-layer 8.5 GB theo slide).
08

CPU · REGISTERS · ADDRESSING

Chapter 04 · PDF + BỔ TRỢ
  • CPU & execution: Fetch → Interpret → Fetch data → Process → Write data. Datapath, Control, ALU, registers, internal bus. Execution modes/privilege bảo vệ hệ thống.
  • Register families: GPR: RAX/RBX/RCX/RDX và EAX/AX/AH/AL; index/pointer: RSI/RDI/RBP/RSP; R8–R15 (x64); segment CS/SS/DS/ES/FS/GS; IP/EIP/RIP; control/status registers.
  • Flags & interrupts: CF, PF, AF, ZF, SF, OF; TF, IF, DF. INTR = maskable (IF); NMI = non-maskable. Exceptions: processor-detected/programmed. 8086 IVT ánh xạ vector → handler; lưu trạng thái → ISR → IRET.
  • Instruction structure & operations: Opcode + operand/address; 0/1/2/3-address; operand: address, number, character, logical. Nhóm lệnh: MOV/LEA/PUSH; ADD/SUB/MUL/DIV/IDIV; AND/OR/XOR/shift/rotate; JMP/CALL/conditional/LOOP; LODS/MOVS.
  • Addressing & Real Mode: Immediate · Direct · Indirect · Register · Register-indirect · Displacement · Relative · Indexed · Based-indexed (+ displacement) · Stack; EA = Base + Index + displacement. 8086: PA = Segment×16 + Offset; 20-bit = 1 MiB; paragraph 16 byte. CS:IP code; DS/ES data; SS:SP/BP stack. Không áp công thức này cho x86-64 long mode.
09

NUMBER SYSTEMS · DATA REPRESENTATION

Chapter 05 · PDF + LAB
  • Bases & conversion: Decimal 10, Binary 2, Octal 8 (digits 0–7), Hex 16. Value = Σ digit×base^position. Integer: chia liên tiếp; fraction: nhân liên tiếp; MSB/LSB là bit trọng số cao/thấp.
  • Signed integers: Unsigned: 0…2ⁿ−1. n-bit two’s-complement: −2ⁿ⁻¹…2ⁿ⁻¹−1. 1’s comp = đảo bit; 2’s comp = đảo + 1. Sign extension: lặp sign bit; luôn giữ đủ n bit.
  • Carry / Overflow: CF báo carry/borrow theo unsigned; OF báo signed result vượt miền. Với phép cộng signed: hai toán hạng cùng dấu nhưng kết quả khác dấu → OF=1.
  • Strings · IEEE 754 · endian: ASCII ký tự → byte; C-string kết thúc 00 ("19653" = 6 byte kể cả null). Single = 1|8|23, bias 127; Double = 1|11|52, bias 1023. Đổi trị tuyệt đối → binary → normalize 1.F×2ᵉ → hidden 1 → exponent e+bias → sign; decode ngược. Little: LSB ở địa chỉ thấp; Big: MSB ở địa chỉ thấp. Ví dụ 0x12345678 → LE 78 56 34 12; BE 12 34 56 78.
  • Memory layout & debugging: Text=code; Data=global/static initialized; BSS=uninitialized/zero; Heap=dynamic; Stack=call frames/local/return. WSL + GCC/GDB: gcc -g -O0; break main; run; next/step; print; x/4xb; continue. NASM ELF64: nasm -f elf64 → ld → ./program.
