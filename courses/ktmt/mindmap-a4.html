INTRODUCTION · COMPUTER ORGANIZATIONChapter 00–01 · Buổi 01
LÝ THUYẾT
Computer Architecture = thuộc tính lập trình viên nhìn thấy (ISA, tập lệnh, kiểu dữ liệu, độ rộng, addressing, I/O). Computer Organization = cách phần cứng hiện thực ISA (datapath, control, bus, tín hiệu, mạch). Structure = quan hệ thành phần; Function = hoạt động.
CẤU TRÚC
Computer = CPU + Main Memory + I/O + System Interconnection. 4 chức năng: Data Processing · Data Storage · Data Movement · Control. Abstraction: Application → High-level language → Assembly → Machine/ISA → Microarchitecture → Digital circuits.
VON NEUMANN / IAS
Stored-program: lệnh và dữ liệu cùng lưu trong memory. IAS: 1,000 words × 40 bit; number = 1 sign + 39 value bits; instruction word có 2 lệnh × 20 bit; mỗi lệnh = 8-bit opcode + 12-bit address. CPU = ALU + Program Control Unit.
IAS REGISTERS
PC: địa chỉ word lệnh kế; MAR: địa chỉ ô nhớ; MBR: word đọc/ghi; IR: opcode đang thực thi; IBR: lệnh phải chờ; AC: accumulator; MQ: multiplier/quotient. Luồng: PC → MAR → MBR → IR/IBR → ALU/AC/MQ.
NHẬN DIỆN
Architecture: lệnh mới hoặc số thanh ghi nhìn thấy bởi lập trình viên. Organization: kích thước cache, cách nối bus, control signals. IAS có thể chứa 2 instruction trong 1 word nhưng CPU vẫn xử lý từng instruction theo control flow.

COMPUTER EVOLUTION · PERFORMANCEChapter 01 · Buổi 02
TIẾN HÓA
Vacuum tube → Transistor → Integrated Circuit → VLSI/ULSI. Moore’s Law mô tả xu hướng tăng mật độ transistor; không đảm bảo tốc độ CPU tăng tương ứng. Memory Wall: tốc độ CPU tăng nhanh hơn khả năng cung cấp dữ liệu của memory.
KỸ THUẬT TĂNG TỐC
Pipelining: chồng lấp các giai đoạn lệnh; không làm một lệnh đơn luôn ngắn hơn. Branch prediction: dự đoán nhánh. Speculative execution: thực thi trước khi biết chắc nhánh. Data-flow analysis: tìm lệnh độc lập. Multicore/MIC/GPGPU: song song ở mức khác nhau.
CÂN BẰNG HỆ THỐNG
CPU phải được cấp dữ liệu bởi Cache → DRAM → Storage và I/O. Clock cao không tự động đồng nghĩa nhanh hơn: xét Instruction Count, CPI, Clock Rate, cache miss, băng thông và workload/benchmark (ví dụ SPEC). x86 thường CISC; ARM thường RISC; embedded ưu tiên ràng buộc công suất/kích thước.
CÔNG SUẤT
Dynamic/active power ≈ C × V² × f × α (C: capacitance; V: voltage; f: frequency; α: switching activity). Static power do leakage. Tăng V làm công suất động tăng theo bình phương; nhiệt và tiêu thụ điện giới hạn tăng tốc.
IRON LAW / METRICS
CPU Time = IC × CPI × Clock Cycle Time = (IC × CPI) / Clock Rate. CPIavg = Σ(fractionᵢ × CPIᵢ). MIPS = IC / (Execution Time × 10⁶); MFLOPS = số phép floating-point / (Time × 10⁶). So sánh CPU trên cùng workload, không chỉ nhìn GHz/MIPS.
CÁCH GIẢI CPU TIME
1) Đổi IC và Clock Rate về cùng đơn vị. 2) Nếu cho CPI theo nhóm: tính CPIavg bằng tỷ trọng instruction. 3) Tính cycles = IC × CPIavg. 4) Time = cycles / Clock Rate. 5) Ghi đơn vị s/ms/ns. Ví dụ: IC=12×10⁶, CPI=2, clock=2×10⁹ Hz → T=0.012 s.
CÁCH GIẢI AMDAHL
Speedup = 1 / [(1−P) + P/S], P = phần được cải thiện; S = speedup của phần đó. 1) Đổi % sang số thập phân. 2) Giữ nguyên phần 1−P. 3) Chia P cho S. 4) Cộng mẫu rồi lấy nghịch đảo. Ví dụ P=.8, S=4 → 1/(.2+.2)=2.5×. Phần không cải thiện đặt giới hạn.
03
INSTRUCTION CYCLE · INTERRUPTSChapter 02 · Buổi 03
COMPUTER FUNCTION
Data Processing · Data Storage · Data Movement · Control. Instruction cycle vận hành nhờ stored-program; luồng mặc định tuần tự, có thể đổi bởi branch/jump hoặc interrupt.
CHU KỲ LỆNH
Fetch → Decode/Interpret → (Indirect nếu cần) → Execute → Store/Write-back. Fetch: PC đưa địa chỉ sang MAR; memory trả word qua MBR; opcode sang IR, lệnh còn lại có thể sang IBR; PC cập nhật theo quy tắc máy. State diagram mô tả các nhánh chu kỳ.
POLLING vs INTERRUPT
Polling: CPU tự kiểm tra trạng thái thiết bị lặp lại, tốn chu kỳ dù chưa có việc. Interrupt: thiết bị báo IRQ; CPU hoàn tất lệnh hiện tại, lưu context, chuyển ISR, xử lý rồi phục hồi. Nguồn: Program · Timer · I/O · Hardware failure.
MULTIPLE INTERRUPTS
Sequential: hoàn tất ISR hiện tại rồi xử lý ngắt kế. Nested: ngắt ưu tiên cao có thể chen vào ISR đang chạy. Trình tự: xác định nguồn/priority → lưu PC & trạng thái → ISR → khôi phục → tiếp tục chương trình.
CÁCH TRUY VẾT IAS
Lập bảng từng bước: PC | MAR | MBR | IR | IBR | AC | MQ. Ở mỗi bước ghi register nhận giá trị nào, từ đâu, lệnh trái/phải được chọn ra sao. IBR giữ right-hand instruction; IR giữ opcode đang thực thi.

BUS · COMPUTER INTERCONNECTIONChapter 02 · Buổi 04
MODULE & TRANSFER
3 module: Processor, Memory, I/O. Transfer: Memory↔CPU; I/O↔CPU; I/O↔Memory (DMA). Shared bus dùng chung đường truyền; point-to-point nối trực tiếp hai endpoint.
3 ĐƯỜNG BUS
Data Bus: mang dữ liệu; Address Bus: chọn địa chỉ; Control Bus: Read/Write, interrupt, request/grant, clock/reset. Bus width quyết định số bit mỗi lần truyền; clock/transfer rate quyết định nhịp; bandwidth phụ thuộc cả hai và giao thức.
ARBITRATION & TIMING
Bus master khởi tạo transfer, slave phản hồi. Arbitration: centralized hoặc distributed. Synchronous: dùng clock chung; asynchronous: handshake/request-acknowledge. Nhiều bus hierarchy giúp giảm bottleneck.
QPI
Point-to-point, packetized, full-duplex. 4 layer: Physical → Link → Routing → Protocol. Flit = 80 bit (64 data + 8 header + 8 error); Phit là đơn vị truyền ở Physical. Giữ riêng thông lượng mỗi hướng và tổng hai hướng.
CÁCH TÍNH QPI / PCIe
QPI ví dụ slide: 3.2 GHz DDR → 6.4 GT/s; ×16 bit ÷8 = 12.8 GB/s mỗi hướng; full-duplex hai hướng = 25.6 GB/s tổng. PCIe: lane x1/x4/x8/x16; throughput/lane ≈ GT/s × encoding efficiency ÷8; nhân số lane. Gen1/2: 8b/10b = 80%; Gen3+: 128b/130b ≈98.46%, chưa trừ packet overhead.

MEMORY HIERARCHY · CACHE BASICSChapter 03 · Buổi 05
MEMORY TRADE-OFF
Đánh giá memory theo Capacity, Access Time, Cost/bit. Bộ nhớ càng gần CPU: nhanh, nhỏ, đắt/bit. Đi xuống hierarchy: capacity tăng, cost/bit giảm, access time tăng, tần suất CPU truy cập giảm.
HIERARCHY
Registers → L1/L2/L3 Cache → Main Memory (DRAM) → Secondary Storage. Cache giữ bản sao block đang có khả năng được dùng lại; I-Cache cho instruction, D-Cache cho data.
LOCALITY
Temporal: vừa dùng gần đây có thể dùng lại. Spatial: địa chỉ lân cận có thể được dùng. Sequential: truy cập tuần tự. Cache line/block tận dụng locality; miss cần nạp block từ tầng dưới.
CACHE HIT / MISS
Hit: dữ liệu nằm trong cache. Miss: không có, phải lấy từ tầng dưới. Hit ratio = Hits/Requests; Miss ratio = 1−Hit ratio. Valid bit báo line có dữ liệu hợp lệ; Dirty bit báo dữ liệu đã bị sửa (write-back).
CÔNG THỨC / CÁCH LÀM
Hit ratio: đếm số request hit rồi chia tổng request. Miss ratio = 1−Hit. AMAT (bổ trợ): Hit time + Miss rate × Miss penalty. Khi mô phỏng truy cập, kiểm tra tag/valid trước; miss thì nạp block và xét replacement/write policy.

CACHE MAPPING · REPLACEMENT · WRITEChapter 03 · Buổi 06
TAG / INDEX / OFFSET
Địa chỉ chia thành Tag | Index (Line/Set) | Block/Word Offset. Offset bits = log₂(block size theo byte/word); Index bits = log₂(number of lines) với Direct, hoặc log₂(number of sets) với Set-associative; Tag = phần bit còn lại.
3 KIỂU MAPPING
Direct: mỗi memory block chỉ vào một line; line = block number mod số lines. Fully associative: block vào bất kỳ line. Set-associative: block vào đúng set và chọn một way; set = block number mod số sets; ways = số line mỗi set.
CÁCH GIẢI ĐỊA CHỈ CACHE
1) Xác định byte/word address và tổng số bit địa chỉ. 2) Tính block size và offset bits. 3) Tính lines/sets và index bits. 4) Phần còn lại là tag. 5) Block→line/set dùng phép mod. 6) So Tag + Valid để kết luận hit/miss. Ví dụ 32-bit, block 16 B, direct cache 64 lines → Offset=4 bit, Index=6 bit, Tag=22 bit.
REPLACEMENT
Khi set đầy, chọn victim: LRU (ít dùng gần đây nhất), FIFO (vào trước ra trước), Random. Direct mapping không chọn way nhưng dễ conflict/thrashing khi nhiều block trùng line.
WRITE POLICY
Write-through: ghi đồng thời cache + memory. Write-back: chỉ ghi cache, ghi về memory khi evict; Dirty bit đánh dấu line thay đổi. Write-allocate / No-write-allocate quyết định có nạp block khi write miss hay không.
07
INTERNAL · EXTERNAL MEMORYChapter 03 · Buổi 07
CHIP CAPACITY
Memory tổ chức W words × N bits/word → capacity = W×N bits. Số đường địa chỉ k = log₂(W). Ví dụ 1K×8: 1024 words, 8 bits/word → 8192 bits = 1024 bytes; cần 10 address lines.
SRAM / DRAM
SRAM: latch/flip-flop, nhanh, không refresh, đắt và mật độ thấp → Cache. DRAM: lưu điện tích tụ, cần refresh, rẻ hơn/mật độ cao → Main memory. RAM là volatile.
ROM / FLASH
ROM: đọc cố định; PROM: lập trình 1 lần; EPROM: xóa bằng UV; EEPROM: xóa/ghi điện; Flash: xóa theo block. Non-volatile. NAND: page read/program, block erase (SSD/USB); NOR: random access, hay dùng firmware.
MAGNETIC DISK
Platter, spindle, head, actuator; bề mặt chia Track/Sector, Cylinder là các track cùng bán kính. Access time ≈ Seek time + Average rotational latency + Transfer time. Average rotation latency (ms) = 30,000/RPM.
CÁCH GIẢI DISK
1) Seek time lấy từ đề. 2) Trot(avg)=30,000/RPM ms. 3) Transfer time đổi cùng đơn vị. 4) Cộng 3 phần. Ví dụ 7200 RPM → Trot(avg)=4.17 ms; nếu seek=5 ms và transfer=.5 ms thì access≈9.67 ms.
RAID / SSD / OPTICAL
RAID 0: striping/no redundancy; 1: mirroring; 2: Hamming ECC; 3: byte-level striping + parity disk; 5: block-level distributed parity; 6: dual distributed parity. SSD: flash, low latency/IOPS cao, có wear và erase-block. Optical: CD-ROM, CD-R, CD-RW, DVD.
08
CPU · REGISTERS · INSTRUCTION · ADDRESSINGChapter 04 · Buổi 08
CPU STRUCTURE
Datapath + Control; ALU xử lý số học/logic; registers giữ toán hạng, địa chỉ và trạng thái; internal bus kết nối. Chu trình: fetch → interpret → fetch operands → process → write result.
REGISTER GROUPS
GPR: RAX/RBX/RCX/RDX (EAX/AX/AH/AL...); index/pointer: RSI/RDI/RBP/RSP; R8–R15 trong x64. Segment: CS, SS, DS, ES, FS, GS. Instruction pointer: IP/EIP/RIP. Control/status: FLAGS/EFLAGS/RFLAGS và control registers.
FLAGS
Condition: CF (carry), PF (parity), AF (aux carry), ZF (zero), SF (sign), OF (overflow). Control: TF (single-step), IF (interrupt enable), DF (string direction). INTR maskable theo IF; NMI non-maskable. Exceptions: processor-detected hoặc programmed; IVT ánh xạ vector → handler.
INSTRUCTION SET
Instruction = Opcode + Operand(s); có 0/1/2/3-address formats. Operand có thể là address, number, character, logical data. Nhóm: data transfer (MOV/LEA/PUSH); arithmetic (ADD/SUB/MUL/DIV); logic/shift (AND/OR/XOR/SHL/SHR); control (JMP/CALL/conditional/LOOP); string (MOVS/LODS).
ADDRESSING MODES
Immediate: hằng trong lệnh; Direct: địa chỉ trực tiếp; Indirect: ô nhớ chứa địa chỉ; Register; Register-indirect; Displacement/Relative/Indexed; Stack. Effective address thường = Base + Index×Scale + Displacement (theo kiến trúc/mode).
8086 REAL MODE
Physical Address = Segment×16 + Offset. Segment base dịch trái 4 bit (paragraph = 16 bytes); bus địa chỉ 20-bit → tối đa 1 MiB. CS:IP code; DS/ES data; SS:SP/BP stack. Đây là 8086 Real Mode, không áp dụng công thức này cho x86-64 long mode.
CÁCH TÍNH PA
1) Đổi Segment và Offset sang cùng hệ hex. 2) Segment×10h (dịch trái 1 hex digit). 3) Cộng Offset. Ví dụ 1234h:5678h → 12340h + 5678h = 179B8h.

NUMBER SYSTEMS · DATA REPRESENTATIONChapter 05 · Buổi 09 + LAB
BASE & BIT
Binary base 2; Octal base 8 (digits 0–7); Decimal 10; Hex 16. Giá trị = Σ digit×base^position. MSB là bit trọng số lớn nhất; LSB nhỏ nhất. Giữ đủ n bit, kể cả leading zero.
CÁCH ĐỔI CƠ SỐ
Integer: chia liên tiếp cho base, ghi remainder từ dưới lên. Fraction: nhân phần lẻ liên tiếp với base, lấy phần nguyên từ trên xuống. Hex↔binary: mỗi hex digit ↔ 4 bit. Ví dụ 45.625₁₀ = 101101.101₂.
SIGNED / TWO’S COMPLEMENT
Unsigned n-bit: 0…2ⁿ−1. Two’s complement: −2ⁿ⁻¹…2ⁿ⁻¹−1. Tạo −x: đảo tất cả bit rồi +1. Sign extension: mở rộng bằng cách lặp sign bit. Ví dụ −18 (8-bit)=11101110; 16-bit=11111111 11101110.
CF vs OF
CF: carry/borrow theo unsigned. OF: kết quả signed vượt miền. Phép cộng signed: hai toán hạng cùng dấu nhưng kết quả trái dấu → OF=1. Ví dụ 100+60 (8-bit): 01100100+00111100=10100000; CF=0, OF=1 (kết quả signed không biểu diễn được +160).
STRING / ENDIAN / MEMORY
ASCII: mỗi ký tự thường 1 byte; C-string có byte 00 kết thúc nên "19653" = 6 bytes. Little-endian: byte thấp ở địa chỉ thấp; Big-endian: byte cao ở địa chỉ thấp. 0x12345678 → LE 78 56 34 12; BE 12 34 56 78. Layout: Text=code; Data=initialized global/static; BSS=uninitialized/zero; Heap=dynamic; Stack=call frame/local/return (compiler có thể tối ưu lưu trữ).
IEEE 754
Single = 1 sign | 8 exponent | 23 fraction, bias=127. Double = 1 | 11 | 52, bias=1023. Normalized: value=(−1)^S × 1.F × 2^(E−Bias). Exponent all-0: zero/subnormal; all-1: infinity/NaN theo fraction.
CÁCH MÃ HÓA IEEE
1) Tách sign S. 2) Đổi |x| sang binary. 3) Chuẩn hóa 1.F×2ᵉ. 4) Exponent field=e+bias. 5) Bỏ hidden leading 1, lấy fraction đủ bit (round nếu cần). 6) Ghép S|E|F rồi đổi hex. Ví dụ 5.75=101.11₂=1.0111×2² → S=0; Single E=2+127=129=10000001; F=0111000… Decode: trừ bias, dựng lại 1.F rồi nhân 2 mũ.
LAB WSL / GDB / NASM
C: gcc -g -O0 file.c -o app; gdb ./app → break main → run → next/step → print var → x/4xb addr → continue. NASM ELF64: nasm -f elf64 file.asm -o file.o; ld file.o -o app; ./app. NASM ELF64 Linux ≠ MASM/TASM 8086 DOS (INT 21h cần emulator/môi trường DOS).
